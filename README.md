# Meetsy

Modern video conferencing platform for seamless online meetings, screen sharing, and team collaboration.

</div>

## Overview

Meetsy is a real-time video conferencing application inspired by modern collaboration platforms. You can create meetings, join rooms instantly, schedule sessions, and communicate securely through a responsive and intuitive interface.

## Features

- Secure Authentication
- Instant Meeting Creation
- Personal Meeting Rooms
- Meeting Scheduling
- Screen Sharing
- Meeting Recording
- Participant Management
- Real-time Communication
- Responsive Design

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Clerk Authentication
- Stream Video SDK
- shadcn/ui

## Getting Started

